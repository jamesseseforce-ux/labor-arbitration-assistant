# 使用示例

以下内容可直接复制。事实越具体，结果越有针对性；不知道的信息可以不填。

## 1. 不知道从哪里开始

```text
使用 $labor-arbitration-assistant：公司欠我4个月工资，大约1万元，我目前还在职。我现在先做什么？
```

## 2. 被口头辞退

```text
使用 $labor-arbitration-assistant：我入职1年3个月，月薪6000元。老板昨天口头让我不要再来，公司没有给书面通知。我想拿钱离开，请告诉我能主张什么。
```

## 3. 直接生成仲裁申请书

```text
使用 $labor-arbitration-assistant：我2024年5月入职，月薪8000元，公司2026年8月违法辞退我，还欠7月工资。请直接生成完整劳动仲裁申请书，缺失的信息留空。
```

## 4. 在职调岗降薪

```text
使用 $labor-arbitration-assistant：公司通知下月把我工资降低30%，我不同意但还想继续工作。请帮我写一段语气温和、能够保留权利的回复。
```

## 5. 未签劳动合同

```text
使用 $labor-arbitration-assistant：我工作8个月一直没签劳动合同，工资每月7000元。请计算可能的二倍工资，并告诉我需要哪些主要材料。
```

## 6. 已经离职、公司资料拿不到

```text
使用 $labor-arbitration-assistant：我已经离职，考勤和工资表都在公司系统里，现在无法登录。我手里只有工资流水和部分微信，请帮我设计证据方案。
```

## 7. 已经申请仲裁

```text
使用 $labor-arbitration-assistant：我已经提交仲裁申请。请根据下面的证据整理正式证据目录、每份证据的证明目的、公司可能的反驳和我的庭审回答。
```

## 8. 一次准备完整材料

```text
使用 $labor-arbitration-assistant：请一次生成仲裁申请书、金额明细、证据目录、质证提纲、向公司的发问清单和仲裁员可能提问的回答。未知事实用【待补】标记。
```

## 建议提供的信息

```text
是否仍在职：
入职／离职日期：
岗位和用工方式：
工资及支付方式：
发生了什么：
公司通知原话：
已有主要材料：
希望继续工作还是拿钱离开：
需要生成的文书：
```
