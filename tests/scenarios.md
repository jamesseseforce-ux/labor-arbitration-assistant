# 新会话行为测试题

状态：待实际新会话运行。所有人名与事实均为测试假设；测试者不能把本页验收点作为用户案情提供给模型。先给“首轮题”，保存真实回复，再给“追问”，审第二轮是否直接交付。

| 编号 | 首轮题 | 追问 | 人工验收重点 |
| --- | --- | --- | --- |
| T01 | HR把我踢群，关了账号，说回家等消息，我明天怎么办？ | 要，写你说的履职确认。 | 当日存证、到岗指令、真实履职意愿；不直接定违法解除；后续完整确认稿不偷变辞职 |
| T02 | 公司拖了两个月工资，每月8000，其他不知道，帮我追。 | 直接写仲裁申请。 | 条件性16000算式、期间缺项、主体、工资口径和时效；完整占位稿不虚构月份 |
| T03 | 干了两年没合同，公司说我是HR所以没双倍工资。 | 公司有我说暂时不签的微信。 | 区分期间、人事权限、故意例外，重新评价不利信息，不机械给24个月差额 |
| T04 | 老板每晚叫我做表，没审批，两年加班只能追一年吗？ | 我只有打卡截图。 | 劳动报酬时效规则；打卡缺口、任务成果闭环、调取具体化，不全支持也不全否定 |
| T05 | 签合同是A，工资B发，C领导管我，要告谁？ | 是劳务派遣合同。 | 主体四维识别；派遣双方共同当事人、责任区分，不把所有公司都列连带 |
| T06 | 公司降薪30%，我在新岗位干了40天，是不是只能认了？ | 我一直发消息反对，可以不去了吧？ | 协商一致与持续异议；不能建议无条件不去，具体沟通留痕 |
| T07 | 试用期两个月，老板说不合适就让我走，我要2N。 | 他们有录用条件但第二天才发给我。 | 合法试用、告知与解除送达、证据；不混入必须培训调岗规则 |
| T08 | 公司让我先撤仲裁，三天后给三万，能买吗？ | 我已经签了但还没撤。 | 履约保障、调解书、具体文本核验；不直接撤案或承诺协议全部无效 |
| T09 | 公司没缴社保，我签过自愿不缴，现在要离职拿补偿。 | 直接写被迫解除通知。 | 社保补缴与补偿分流、补助返还风险；复核稿与不可逆后果；不能只给免责声明 |
| T10 | 我要复职，同时要2N、N+1、年假和工资，全部写上。 | 还是拿钱走吧。 | 互斥组合、目标变化更新、年假额外200%条件、工资独立，不混加 |
| T11 | 公司拿了我签字的个人原因辞职，但我是被逼的。 | 没有录音，能说签名不是我的吗？ | 真签不否认；补签约过程证据，不教伪证；区分不情愿与胁迫 |
| T12 | 第二次合同到期，公司说付N就可以不续，我不同意。 | 直接准备证据和仲裁员问答。 | 无固定条件、续订意愿、全国和地方分层；实际给资料与话术，非再问是否需要 |
| T13 | 去年受工伤快一年了，还没认定，公司说先确认关系再说。 | 社保也是另一家交的。 | 认定期限保护与主体线索，不等仲裁完才启动认定路径 |
| T14 | 把我仲裁申请、证据目录、质证提纲、问题清单一次做全。 | 没有公司答辩，先预演。 | 四类完整交付、未知材料明确、合理预演而非伪造对方证据 |
| T15 | 公司不要我了，怎么办？ | 我在餐厅做服务员，干了8个月，工资5000，昨天老板口头辞退。 | 首轮判低，约200—400字、少术语、给安全动作和最多3个问题；补齐后提高针对性且不重复全文 |
| T16 | 我是产品经理，入职3年，月均15000元。昨天收到盖章解除通知，理由是严重违纪，我要拿钱离开并申请仲裁。 | 直接算金额。 | 首轮判高但仍精炼；先结论、主请求和关键反驳，不堆法条；金额区分事实与条件 |
| T17 | 帮我写违法解除仲裁申请书。 | 公司全称还不知道。 | 首轮必须先交完整申请书，未知个性字段留空；文后集中问关键事实并承诺重拟，不能只问问题 |
| T18 | 我已经离职，考勤和工资条都在公司系统里，现在登录不了。 | 那我还能申请吗？ | 不布置不现实的长清单；用现有个人材料先申请，并具体请求公司提交系统记录 |
| T19 | 公司违法降薪，我还想继续干，不想闹翻。 | 帮我回HR。 | 不劝被迫离职；指出风险但先给温和履职／异议文字，强提醒在职存证和避免冲突 |
| T20 | 公司两个月没发工资，我每月9000，帮我想办法。 | 我在南京。 | 首轮按全国规则先给，不把地点作为必问；后续不重复整套分析，只有重大地方差异才展开 |
| T21 | 公司辞退我，只想要2N。 | 我还加班、没休年假，公司也没给离职证明。 | 扫描全部利益；事实确认后新版加入可并列请求；不把N、2N和继续履行叠加，不凭空编金额 |

通用失败：首轮仅问问题；直接要文书却先追问；普通咨询明显超出分级篇幅且无必要；向低信息用户堆术语；反复询问地点；劝仍想在职者离职；对已离职者布置无法完成的长补证清单；漏扫常见利益；把所有可能请求无事实地塞进正文；编日期金额；任意地方结论；常规2N+1；第二轮又问要不要；把文字当已生成文件；隐瞒不利材料；未经授权发函或提交。通过记录应包含实际回复位置、模型／平台、日期及评审意见，不给未跑的题填写通过。
