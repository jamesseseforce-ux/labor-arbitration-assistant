# 从事实到可执行方案

## 建立最小案件底稿

持续更新而非每轮重问：用户目标（继续工作／拿钱离开／追薪）、在职状态、用工主体、入职日、岗位、签约记录、工资构成、实际工时、社保、争议事件、解除与送达、已签文件、已投诉或申请、举证或开庭期限。工作地点和拟申请机构只在管辖或地方规则确会影响下一步时补问；姓名身份证只在实名文书中留占位，不要求用户在聊天中公开。

每条记录区分：用户陈述／材料显示／合理推测／代理意见。证据状态四类是“已有但待验真、缺失、矛盾、待核实”；不要把“用户说有”标成已阅证据。日期有冲突时保留两个版本及其影响，不择取对己最有利的一版当真。

## 主体与用工模式

| 模式 | 最少核验 | 劳动者策略 |
| --- | --- | --- |
| 直接用工 | 合同公章与名称、信用代码、招聘及日常管理、工资付款附言、社保 | 无合同不等于无劳动关系；管理从属性、持续劳动、报酬相互印证；登记地址不等于履行地 |
| 总公司和分公司 | 分公司登记及营业执照、是否获授权签约、实际用工、存续情况 | 依实施条例第四条核验签约主体资格；分公司不独立法人不等于不能作为当事人，列总公司或追加须说明具体依据及当地要求 |
| 关联公司交替或共同用工 | 每段合同、管理指令、发薪和社保主体、变更是否本人原因、有无补偿 | 按解释（二）第三条区分有合同和无合同；共同报酬福利责任不自动扩展为全部赔偿连带责任；保存工龄连续性材料 |
| 派遣 | 派遣合同、派遣许可、实际用工、退回通知、解除通知 | 派遣单位与用工单位共同当事人；“退回”不等于劳动合同已解除，各自义务和连带条件分开论证 |
| 外包、承揽、合作、个体户、平台 | 谁定价格排班考核奖惩、能否自主接单替代履行、工具和经营风险 | 合同名不能替代履行事实；确有独立经营时备选劳务报酬民事路径；违法转分包的用工主体责任不等于当然劳动关系 |
| 非全日制 | 实际平均日工时、周工时、结算周期、其他雇主 | 核验每日一般不超4小时、每周累计不超24小时；可口头协议、不得约定试用期、终止通常无经济补偿，不能套全日制二倍工资 |
| 退休、实习等边界 | 年龄与适用退休规则、养老待遇领取、学生身份与真实用工 | 不凭年龄或“实习”字样直接否认；当期退休与超龄用工政策另核，不硬编码旧男女年龄 |

管辖优先核劳动合同履行地或用人单位所在地；双方分别申请时履行地优先。仲裁协议不得任意替代法定管辖。申请主体全称和信用代码与登记资料交叉核验，欠薪不能仅告没有用人主体身份的HR个人。

## 解除事实决策

1. 对方说“你走吧”／停权：保存全段沟通，问清是否作出解除、理由、生效日、后续工作及考勤。本人愿意且能够继续工作时，真实表达履职意愿；不强行闯入、不虚构到岗。停权前后截图、到场记录与回复一并保存。
2. 有单位解除通知：固定最初版本、日期、理由及送达，核验决定者权限。围绕当时理由反驳；新理由标记为事后追加，不主动帮公司补齐。
3. 已签个人原因辞职：先读全文、签字过程、撤回情况和前后谈话。区分真实辞职、公司要求代写、欺诈胁迫及协议解除；不能把所有不情愿一律叫胁迫，也不能说签字后绝无救济。
4. 单位提出协商解除：查提出方和一致意思、签字生效条件、钱款与清结范围。争取细分已得工资与让步补偿，确认履行保障后再处理撤案。
5. 劳动者考虑第三十八条解除：先确认其确有离职意思。仍在职且想保住工作时，优先用温和的整改、核对或履职确认文字，不能因单位存在违法就鼓动离职。只有决定离职时才核具体违约、期间、证据和地方口径，并说明通知送达会结束劳动关系、停止后续工资、锁定理由；普通辞职不能事后自动改成此路径。
6. 到期不续签：查合同次数、连续工龄、保护期、自动续延、本人续订意愿和历次主体变换。N不是企业买断任何违法终止的价格。

## 请求组合与程序分流

先做全请求扫描，再区分“已有事实支持”“核实后可增加”“互斥备选”，不漏掉劳动者可能取得的利益，也不把它们混成必得总数。

- 同一解除：继续履行及恢复期间工资与2N为不同救济路径；确认真实目标和履行可能，必要时依当地程序设置备位或变更请求，不同时要求全部最终实现。
- 同一解除N与2N不重复；第40条代通知金也不作为所有辞退的自动加项。工资、合适期间的二倍工资差额、未休年假等可与解除请求并列但逐项去重。
- 未签满一年后“视为无固定”与违反应订无固定义务不同。不同二倍工资基础同一期间不得重复；不要将所有情形统一上限11个月。
- 社保欠费先查社保、税务或人社的当地征缴分工；补缴不是支付到劳动者账户的工资。不能补办造成实际待遇损失时再审仲裁赔偿路径、损失和因果。
- 离职案件主动核失业保险：单位解除或劳动者依法依第三十八条解除可能涉及非本人意愿中断就业；因单位错误记载离职原因、未参保等导致确实不能领取时，再审待遇损失请求。未申请、仍可补办或损失不明时不能直接虚列金额。
- 欠薪可考虑劳动监察和仲裁，记录投诉范围、收件日期和回执；监察调查时限、证据保存期限与仲裁时效不同。不得保证“投诉必然中断所有请求的时效”。
- 工伤先保护诊疗、事故和用工证据，核单位30日申请及劳动者／近亲属／工会1年申请窗口和当地扣除情形；关系有争议时研究确认关系与认定衔接，不等关系案结束才咨询认定期限。认定、鉴定、待遇分别办理。
- 仲裁后看裁决类型和送达：劳动者不服通常15日起诉；单位针对终局裁决撤销通常30日且有法定理由；生效未履行再核执行申请期间（一般2年）及中断中止。提供准确起算、证据和尽早办理日，不仅背数字。

即将超期：准备基本申请、具体请求、身份与被申请人信息及初步证据，核验窗口收件；拿收件凭证、补正通知并按期补正。材料提交不等于当然有效立案或当然产生全部时效效果。
